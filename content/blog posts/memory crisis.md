---
title: 内存危机、刚需与购买决策
created: 2026-07-24
---
23号凌晨，我用一小时做了一个决定：购买一根雷克沙 24GB DDR5 5600 内存条。

起因是我的拯救者笔记本，在我当前的使用情况下，已经有 80% 的时间内存占用率达到 90%+，甚至还见过 99%。这导致的结果是我的电脑长期卡顿，不论是我日常使用的 Chrome 浏览器、Obsidian 和 Codex（ChatGPT App），还是鼠标的移动和点击，都有 1000ms 以上延迟。这已经严重影响我的日常使用。

起初我怀疑是 Chrome 以及 Obsidian 等 Electron 软件的硬件加速导致，控制变量修改过，没有解决问题。后来我也怀疑过是系统版本问题，当然 Windows 11 作为一座屎山，即使核心问题出自 Windows 11 我也无能为力，我也不会把主力机换成 MacBook 或者装 Linux。

后来我怀疑是内存泄漏问题，用 Codex 盘了几轮，又用 RAMMap 检查过数次 Mapped File 和 Paged Pool 等等，不过没有明显的内存泄漏现象。后来我还尝试 Empty Working Sets 以及 Empty Modified Page List，短时间内可以降低内存占用，但治标不治本，最终内存占用仍会随着使用上升。最后我的解决方案导向了购买一根新的内存条。

这个想法其实已经持续了半个多月，从我电脑开始出现爆内存的情况开始。毫无疑问这是最简单的解决方案，前提是没有内存泄漏或者系统本身的原因导致内存占用高。经过几次排查都没有发现系统或软件层面的问题，因此只能从硬件层面解决。

这又带来另一个问题：现在的消费级内存条价格已经贵过金子，我是否有必要在高点入手？不过换个思路，我现在不入手，在可以预见的未来几年，内存价格都是会继续涨的。我对于内存的需求已是刚需，刚需便无所谓涨价还是降价了。用当前能够付出的成本解决当下最严重的问题是我的主要矛盾。

最开始的目标是一根适配笔记本的 16G DDR5 5600 内存条，在淘宝稍作搜索，主要品牌（三星、英睿达、雷克沙、联想拯救者、美光等）这个配置的内存条价格都在 1300-1500 元范围，32GB DDR5 5600 到了 2000 甚至 3200+ 元的范围。 

突然我发现一根雷克沙 24GB DDR5 5600，价格只需要 1399 元，在这个市场下突然有了巨大性价比。于是我开始查阅相关信息：这根内存条是否适配我的电脑，能否与机器自带的 16GB DDR5 5600 适配，是否有无理由退货等等，答案全为是，且三天内送达，于是确认购买该型号内存条。

突然另一个思路拦住我，万一京东有更便宜的呢？于是打开京东搜到同款，发现型号价格一致，额外还多了7天价保和90天只换不修，甚至可以当天送达：此时已经是凌晨快2点，竟然当天下午可以送达，对我而言是巨大利好。于是果断下单。我这台拯救者有更新的 BIOS 版本，花了20分钟更新，后续就等内存送到了。

第二天下午约6点，京东打来电话，东西已经放到门口，马上收拾开始工作。家中原有一套螺丝工具，刚好有 PH0 和 PH1 批头，用来拆机妥妥够用。简单查阅视频，重要的注意事项如释放静电和断电都已习得，但步骤卡在缺乏翘片，花了些许时间。反倒是内存条的包装盒怎么也打不开，把指甲缝割伤了，还是夫人帮忙才能打开。拆完机顺便清了灰，合盖插电点亮，顺利开机！顺便跑了一下内存检测，没有任何问题，电脑已经成功识别 40GB 内存容量。今天用 CPU-Z 再跑了一遍详情，一切正常，16GB + 24GB 的配置不会带来明显的兼容性问题。

此时此刻，我的内存占用是 47%，同时开着的应用有：Chrome 若干标签页，两个 Obsidian，ChatGPT App，微信，FlClash，OneDrive，PotPlayer 和 Notepad--。内存使用量已经来到 18.3GB，换作是以前仅 16GB 内存，现在我的电脑已经卡得不行了。不出意外的话，这个配置足够我用到起码2028年底，彼时内存行业供需趋近平衡，价格理性化，可以再考虑换机需求。

果然有时候还得当下迅速做决策，在涉及刚需的购买需求上，晚一段时间价格就会发生巨大变化。这个决策过程尤其需要感谢我的夫人，在短时间内用严密的逻辑说服了我。去年的这个时候，这根内存条大约只要四五百，如果是2024年，三百出头就可以买到了。现在想来有些许后悔，不过也许过多半年，价格可能要爬到 1800 元左右。
